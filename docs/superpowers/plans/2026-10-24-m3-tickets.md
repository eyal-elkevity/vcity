# M3: Tickets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** File the city's tickets in Linear (ask 3), reliably and idempotently, with a reference number the caller can quote even when Linear is down. Turn repeated questions that the city's records can't answer into one deduplicated, self-prioritising `gap` ticket each.

**Architecture:**
- **`vcity.domain.tickets`** is pure. It holds `Priority`, `ServiceRequest`, `TicketRef` and the reference code.
- **`vcity.tickets`** holds the adapters:
  - pure ticket drafts
  - a `TicketSink` port, with `MockSink`
  - a typed Linear GraphQL client and `LinearSink`, which also implements the `GapBoard` port
  - a SQLite-backed `OutboxSink`
  - `GapBacklog`: a queue-fed background worker that implements M2's `GapLog` port
- Linear is the source of truth for gap tickets. Embedding vectors are only a cache in memory.

**Tech Stack:** Python 3.12, httpx (Linear GraphQL), Pydantic camel-case response models, SQLite (outbox), Voyage query embeddings (gap clustering), pytest with `httpx.MockTransport`.

**Spec:** `docs/spec.md` §7 (tickets, including the gap backlog stretch goal, which the user chose on 2026-10-24) and §12 (engineering standard).

## Decisions this plan makes (review these first)

Everything below was prototyped on 2026-10-24 against the real Linear workspace "vcity corona" and the real Voyage API. The code in every task passed ruff, strict pyright and pytest in a scratch clone (201 tests), and the live tests created and then deleted real issues.

| # | Question | Decision | Alternatives |
|---|---|---|---|
| D1 | Where do tickets go? | The Linear team **Corona 311** (key `COR`). Each department is a label (its display name from `departments.yaml`), plus a `gap` label. An idempotent setup script creates them, **and it has already run**: the team and labels exist. | Use the default team "Vcity corona" (VCI) and skip the setup script. That's less clean, and the spec names "Corona 311". |
| D2 | How do retries avoid duplicate tickets? | The client generates the issue UUID and sends it to Linear. A repeat create gets "conflict on insert of Issue" (verified), and the sink then fetches the existing issue. Retries and outbox delivery are therefore idempotent. | Search for a duplicate before creating. That's racy and costs an extra call. |
| D3 | What reference does the caller hear? | Six digits derived from the UUID, e.g. "417209", read out digit by digit and written into the ticket title. It is the same for a queued ticket, so callers always get a number. | Linear's `COR-42`. It's unavailable when Linear is down, so callers would get two kinds of reference. |
| D4 | Service ticket priority | `NONE`, so staff triage. The description carries the spec §7 fields: call ID, reason, summary, location, callback (`none (browser call)` when absent), plus "Office reopens" when known. | Map reasons to priorities, e.g. transfer failed → high. That's guesswork about city policy. |
| D5 | Port shape | Split into **`TicketSink.create`**, which the outbox wraps, and **`GapBoard`** (`open_gaps`, `file_gap`, `add_ask`, `asks`, `update_gap`). `LinearSink` implements both. | The spec's single 4-method protocol (`create`/`find_open`/`comment`/`set_priority`). It forces the outbox and the mock to implement gap methods they never use. **This deviates from spec §7's signature.** |
| D6 | Outbox | 2 attempts with a 3 s timeout each, then a SQLite queue. `flush()` and `run(interval)` re-send idempotently (D2). Render's disk is ephemeral, so the queue survives the process, not a redeploy. | Keep it in memory only (lost on any crash), or use an external queue (cost). |
| D7 | How are repeated questions recognised? | By the cosine of Voyage query embeddings against the open gap tickets' questions, at **≥ 0.48**. Measured: paraphrases scored ≥ 0.50 and different topics ≤ 0.45. Open gaps are read from Linear on each ask, and vectors are cached per ticket, so restarts lose nothing. | Exact text match after normalising (misses paraphrases), or a local cluster store (lost on Render restarts). |
| D8 | Gap statistics and priority | Each ask is a comment `+1 from caller <hash>: <question>`. After every ask, the description is regenerated: total asks, asks in 7 days, distinct callers, first and last seen in city time, and the 3 latest phrasings. Priority is set from the 7-day count: 1 → low, 3 → medium, 10 → high (the spec's thresholds). | Keep the counters in the description and increment them, which is fragile under concurrent edits. |
| D9 | How do gaps reach the backlog? | `GapBacklog` implements M2's `GapLog`. `record()` is synchronous and only enqueues (zero latency for the caller), and `run()` is a background worker. Only `no_match` is filed, because `off_topic` includes injection attempts (an M2 carry-over). The query is scrubbed and the caller HMAC-hashed with M2's functions. Failures are logged and dropped. | File inline during the call, which adds Linear latency to a voice turn. |
| D10 | Both logs at once | `CompositeGapLog(jsonl, backlog)` fans each entry out to both. | Make `CitySearch` take a list of logs (changes M2's API). |
| D11 | Linear client | httpx GraphQL with named operations and Pydantic models using a camel-case alias generator. Linear has no official Python SDK. | Generated clients (heavy) or untyped dicts (pyright-strict noise). |
| D12 | Tests | Unit tests fake Linear with `httpx.MockTransport`. Live tests (`-m live`) create real issues and delete them. | Mocks only, which would miss real API semantics like the conflict error. |
| D13 | Who starts the background loops and sets timeouts? | M4's composition root, along with the `search_city`/`route_request` wiring. | Wire them now, with no app to host them. |

**Measured facts:**
- Linear allows 2,500 requests an hour.
- Linear rejects a nested team-plus-labels query as "too complex", so the sink and setup make two queries.
- A live gap ticket's description reads, for example, "Total asks: 2 · Distinct callers: 2 · …".

```python
from dataclasses import dataclass
from enum import IntEnum
from uuid import UUID

from vcity.domain.departments import Department

REFERENCE_DIGITS = 6


class Priority(IntEnum):
    # Linear's priority scale: 0 is unset and 1 is the most urgent.
    NONE = 0
    URGENT = 1
    HIGH = 2
    MEDIUM = 3
    LOW = 4


@dataclass(frozen=True, slots=True)
class ServiceRequest:
    call_id: str
    department: Department
    summary: str
    location: str | None
    callback_number: str | None


@dataclass(frozen=True, slots=True)
class TicketRef:
    reference: str
    url: str | None

    @property
    def queued(self) -> bool:
        return self.url is None


def reference_code(ticket_id: UUID) -> str:
    return f"{ticket_id.int % 10**REFERENCE_DIGITS:0{REFERENCE_DIGITS}d}"
```

```python
from dataclasses import dataclass
from datetime import datetime
from typing import assert_never
from uuid import UUID

from vcity.domain.hours import TicketReason
from vcity.domain.tickets import Priority, ServiceRequest, reference_code

MAX_TITLE_SUMMARY = 80
GAP_TITLE_PREFIX = "Unanswered: "


@dataclass(frozen=True, slots=True)
class TicketDraft:
    id: UUID
    title: str
    description: str
    labels: frozenset[str]
    priority: Priority

    @property
    def reference(self) -> str:
        return reference_code(self.id)


def service_ticket(
    request: ServiceRequest,
    reason: TicketReason,
    department_name: str,
    *,
    ticket_id: UUID,
    next_open: datetime | None,
) -> TicketDraft:
    lines = [
        f"**Call:** {request.call_id}",
        f"**Why a ticket:** {_reason_text(reason)}",
        f"**Summary:** {request.summary}",
        f"**Location:** {request.location or 'not given'}",
        f"**Callback:** {request.callback_number or 'none (browser call)'}",
    ]
    if next_open is not None:
        lines.append(f"**Office reopens:** {next_open:%A, %B %-d at %-I:%M %p}")
    return TicketDraft(
        id=ticket_id,
        title=f"[{reference_code(ticket_id)}] {department_name}: {_shorten(request.summary)}",
        description="\n\n".join(lines),
        labels=frozenset({department_name}),
        priority=Priority.NONE,
    )


def gap_ticket(question: str, label: str, *, ticket_id: UUID) -> TicketDraft:
    return TicketDraft(
        id=ticket_id,
        title=f"{GAP_TITLE_PREFIX}{_shorten(question)}",
        description=(
            "Callers asked this and the city's records had no answer. "
            "Each further ask is added as a comment."
        ),
        labels=frozenset({label}),
        priority=Priority.LOW,
    )


def _reason_text(reason: TicketReason) -> str:
    match reason:
        case TicketReason.AFTER_HOURS:
            return "called outside office hours"
        case TicketReason.HOLIDAY:
            return "called on a city holiday"
        case TicketReason.CLOSING_SOON:
            return "called just before the office closed"
        case TicketReason.TRANSFER_FAILED:
            return "the transfer was not answered"
        case TicketReason.CALLER_REQUESTED:
            return "the caller asked for a ticket"
        case _:
            assert_never(reason)


def _shorten(text: str) -> str:
    flat = " ".join(text.split())
    return flat if len(flat) <= MAX_TITLE_SUMMARY else f"{flat[: MAX_TITLE_SUMMARY - 1]}…"
```

```python
class TicketSinkError(RuntimeError):

class TicketSink(Protocol):
```

```python
from collections.abc import Mapping
from types import TracebackType
from typing import Self

import httpx
from pydantic import BaseModel, ConfigDict, TypeAdapter, ValidationError
from pydantic.alias_generators import to_camel

from vcity.tickets.sinks import TicketSinkError

LINEAR_GRAPHQL_URL = "https://api.linear.app/graphql"


class LinearError(TicketSinkError):
    pass


class LinearConflictError(LinearError):
    pass


class LinearModel(BaseModel):
    model_config = ConfigDict(alias_generator=to_camel, frozen=True)


class _GraphQLError(BaseModel):
    message: str
    extensions: dict[str, object] = {}


class _Envelope(BaseModel):
    data: object = None
    errors: list[_GraphQLError] = []


class LinearClient:
    def __init__(self, http: httpx.AsyncClient) -> None:
        self._http = http

    @classmethod
    def connect(cls, api_key: str, *, timeout: float = 5.0) -> Self:
        return cls(
            httpx.AsyncClient(
                base_url=LINEAR_GRAPHQL_URL,
                headers={"Authorization": api_key},
                timeout=timeout,
            )
        )

    async def __aenter__(self) -> Self:
        return self

    async def __aexit__(
        self,
        exc_type: type[BaseException] | None,
        exc: BaseException | None,
        traceback: TracebackType | None,
    ) -> None:
        await self._http.aclose()

    async def execute[T](self, query: str, variables: Mapping[str, object], result: type[T]) -> T:
        try:
            response = await self._http.post("", json={"query": query, "variables": variables})
        except httpx.HTTPError as error:
            raise LinearError(f"Linear request failed: {error}") from error
        envelope = _envelope(response)
        if envelope.errors:
            messages = "; ".join(error.message for error in envelope.errors)
            if any(error.message.startswith("conflict on insert") for error in envelope.errors):
                raise LinearConflictError(messages)
            raise LinearError(f"Linear rejected the request: {messages}")
        if response.is_error:
            raise LinearError(f"Linear returned HTTP {response.status_code}")
        try:
            return TypeAdapter(result).validate_python(envelope.data)
        except ValidationError as error:
            raise LinearError(f"unexpected Linear response: {error}") from error


def _envelope(response: httpx.Response) -> _Envelope:
    try:
        return _Envelope.model_validate_json(response.content)
    except ValidationError:
        return _Envelope()
```

```python
import asyncio
import logging
import math
import re
import uuid
from collections.abc import Callable, Sequence
from dataclasses import dataclass, field
from datetime import datetime, timedelta
from typing import Protocol

from vcity.domain.tickets import Priority
from vcity.knowledge.embeddings import Embedder, Vector
from vcity.knowledge.gap_log import hash_caller, scrub
from vcity.knowledge.model import SearchStatus, SourceKind
from vcity.tickets.drafts import TicketDraft, gap_ticket
from vcity.tickets.sinks import TicketSinkError

GAP_LABEL = "gap"
ANONYMOUS = "anonymous"
_ASK_LINE = re.compile(r"^\+1 from caller (?P<caller>\S+): (?P<question>.+)$", re.DOTALL)
_log = logging.getLogger(__name__)


@dataclass(frozen=True, slots=True)
class GapTicket:
    id: str
    reference: str
    question: str
    created_at: datetime


@dataclass(frozen=True, slots=True)
class Ask:
    caller: str
    question: str
    at: datetime


class GapBoard(Protocol):
    async def open_gaps(self) -> list[GapTicket]: ...

    async def file_gap(self, draft: TicketDraft) -> GapTicket: ...

    async def add_ask(self, gap: GapTicket, body: str) -> None: ...

    async def asks(self, gap: GapTicket) -> list[Ask]: ...

    async def update_gap(self, gap: GapTicket, description: str, priority: Priority) -> None: ...


@dataclass(frozen=True, slots=True)
class GapPolicy:
    similarity: float = 0.48
    window: timedelta = timedelta(days=7)
    thresholds: tuple[tuple[int, Priority], ...] = (
        (10, Priority.HIGH),
        (3, Priority.MEDIUM),
        (1, Priority.LOW),
    )
    samples: int = 3


def ask_line(caller: str, question: str) -> str:
    return f"+1 from caller {caller}: {question}"


def parse_ask(body: str, at: datetime) -> Ask | None:
    match = _ASK_LINE.match(body)
    return Ask(match["caller"], match["question"], at) if match else None


def priority_for(recent_asks: int, policy: GapPolicy) -> Priority:
    return next(
        (priority for minimum, priority in policy.thresholds if recent_asks >= minimum),
        Priority.NONE,
    )


def cosine(a: Vector, b: Vector) -> float:
    dot = sum(x * y for x, y in zip(a, b, strict=True))
    return dot / (math.sqrt(sum(x * x for x in a)) * math.sqrt(sum(y * y for y in b)))


def closest(
    vector: Vector, candidates: Sequence[tuple[GapTicket, Vector]], threshold: float
) -> GapTicket | None:
    scored = [(cosine(vector, other), gap) for gap, other in candidates]
    best = max(scored, key=lambda pair: pair[0], default=None)
    return best[1] if best is not None and best[0] >= threshold else None


def recent_count(asks: Sequence[Ask], now: datetime, policy: GapPolicy) -> int:
    return sum(now - ask.at <= policy.window for ask in asks)


def describe(asks: Sequence[Ask], now: datetime, policy: GapPolicy) -> str:
    ordered = sorted(asks, key=lambda ask: ask.at)
    callers = {ask.caller for ask in asks if ask.caller != ANONYMOUS}
    lines = [
        "Callers asked this and the city's records had no answer.",
        f"**Total asks:** {len(asks)}",
        f"**Asks in the last {policy.window.days} days:** {recent_count(asks, now, policy)}",
        f"**Distinct callers:** {len(callers)}",
        f"**First seen:** {ordered[0].at.astimezone(now.tzinfo):%Y-%m-%d %H:%M %Z}",
        f"**Last seen:** {ordered[-1].at.astimezone(now.tzinfo):%Y-%m-%d %H:%M %Z}",
        "**Recent phrasings:**",
        *(f"- {ask.question}" for ask in reversed(ordered[-policy.samples :])),
    ]
    return "\n\n".join(lines)


@dataclass(frozen=True, slots=True)
class _Miss:
    question: str
    caller: str


@dataclass
class GapBacklog:
    board: GapBoard
    embedder: Embedder
    salt: str
    clock: Callable[[], datetime]
    policy: GapPolicy = field(default_factory=GapPolicy)
    _queue: asyncio.Queue[_Miss] = field(default_factory=asyncio.Queue[_Miss], init=False)
    _vectors: dict[str, Vector] = field(default_factory=dict[str, Vector], init=False)

    def record(
        self,
        *,
        at: datetime,  # noqa: ARG002
        query: str,
        kind: SourceKind | None,  # noqa: ARG002
        status: SearchStatus,
        caller_id: str | None,
    ) -> None:
        if status is not SearchStatus.NO_MATCH:
            return
        caller = hash_caller(caller_id, self.salt) if caller_id else ANONYMOUS
        self._queue.put_nowait(_Miss(scrub(query), caller))

    async def run(self) -> None:
        while True:
            miss = await self._queue.get()
            try:
                await self.file(miss.question, miss.caller)
            except TicketSinkError:
                _log.warning("could not file gap %r; dropping it", miss.question, exc_info=True)
            finally:
                self._queue.task_done()

    async def drain(self) -> None:
        await self._queue.join()

    async def file(self, question: str, caller: str) -> GapTicket:
        vector = await self.embedder.embed_query(question)
        gaps = await self.board.open_gaps()
        candidates = [(gap, await self._vector(gap)) for gap in gaps]
        match = closest(vector, candidates, self.policy.similarity)
        if match is None:
            created = await self.board.file_gap(
                gap_ticket(question, GAP_LABEL, ticket_id=uuid.uuid4())
            )
            self._vectors[created.id] = vector
            match = created
        await self.board.add_ask(match, ask_line(caller, question))
        asks = await self.board.asks(match)
        now = self.clock()
        await self.board.update_gap(
            match,
            describe(asks, now, self.policy),
            priority_for(recent_count(asks, now, self.policy), self.policy),
        )
        return match

    async def _vector(self, gap: GapTicket) -> Vector:
        if gap.id not in self._vectors:
            self._vectors[gap.id] = await self.embedder.embed_query(gap.question)
        return self._vectors[gap.id]
```

```python
class LinearSink:
    def __init__(self, client: LinearClient, team_id: str, label_ids: Mapping[str, str]) -> None:
        self._client = client
        self._team_id = team_id
        self._label_ids = dict(label_ids)

    @classmethod
    async def connect(cls, client: LinearClient, team_key: str = TEAM_KEY) -> Self:
        team_id = await find_team(client, team_key)
        if team_id is None:
            raise LinearError(
                f"Linear team {team_key} is missing; run python -m vcity.tickets.linear_setup"
            )
        return cls(client, team_id, await team_labels(client, team_id))

    async def create(self, draft: TicketDraft) -> TicketRef:
        issue = await self._create_issue(draft)
        return TicketRef(draft.reference, url=issue.url)

    async def open_gaps(self) -> list[GapTicket]:
        result = await self._client.execute(
            _OPEN_GAPS, {"team": self._team_id, "label": GAP_LABEL}, _IssuesResult
        )
        return [_gap(issue) for issue in result.issues.nodes]

    async def file_gap(self, draft: TicketDraft) -> GapTicket:
        return _gap(await self._create_issue(draft))

    async def add_ask(self, gap: GapTicket, body: str) -> None:
        await self._client.execute(
            _COMMENT, {"input": {"issueId": gap.id, "body": body}}, _CommentResult
        )

    async def asks(self, gap: GapTicket) -> list[Ask]:
        result = await self._client.execute(_COMMENTS, {"id": gap.id}, _CommentsResult)
        parsed = (parse_ask(c.body, c.created_at) for c in result.issue.comments.nodes)
        return [ask for ask in parsed if ask is not None]

    async def update_gap(self, gap: GapTicket, description: str, priority: Priority) -> None:
        await self._client.execute(
            _UPDATE,
            {"id": gap.id, "input": {"description": description, "priority": int(priority)}},
            _UpdateResult,
        )

    async def _create_issue(self, draft: TicketDraft) -> _Issue:
        unknown = draft.labels - self._label_ids.keys()
        if unknown:
            raise LinearError(f"labels missing in Linear: {sorted(unknown)}")
        payload = {
            "id": str(draft.id),
            "teamId": self._team_id,
            "title": draft.title,
            "description": draft.description,
            "priority": int(draft.priority),
            "labelIds": sorted(self._label_ids[label] for label in draft.labels),
        }
        try:
            result = await self._client.execute(_CREATE, {"input": payload}, _CreateResult)
        except LinearConflictError:
            existing = await self._client.execute(_ISSUE, {"id": str(draft.id)}, _IssueResult)
            return existing.issue
        return result.issue_create.issue


async def find_team(client: LinearClient, team_key: str) -> str | None:
    result = await client.execute(_FIND_TEAM, {"key": team_key}, _TeamsResult)
    return result.teams.nodes[0].id if result.teams.nodes else None


async def team_labels(client: LinearClient, team_id: str) -> dict[str, str]:
    result = await client.execute(_LABELS, {"team": team_id}, _LabelsResult)
    return {label.name: label.id for label in result.issue_labels.nodes}


def _gap(issue: _Issue) -> GapTicket:
    return GapTicket(
        id=issue.id,
        reference=issue.identifier,
        question=issue.title.removeprefix(GAP_TITLE_PREFIX),
        created_at=issue.created_at,
    )
```

```python
    if (team_id := await find_team(client, TEAM_KEY)) is not None:
        return team_id
    created = await client.execute(
        _CREATE_TEAM, {"input": {"name": TEAM_NAME, "key": TEAM_KEY}}, _CreateTeamResult
    )

    labels = await team_labels(client, team_id)
    for name in names:
        if name not in labels:
            created = await client.execute(
                _CREATE_LABEL, {"input": {"name": name, "teamId": team_id}}, _CreateLabelResult
            )
            labels[name] = created.issue_label_create.issue_label.id
    return labels

    parser.parse_args(argv)

        team_id = await ensure_team(client)
```

```python
import asyncio
import logging
import sqlite3
from contextlib import closing
from pathlib import Path
from uuid import UUID

from pydantic import BaseModel, ConfigDict

from vcity.domain.tickets import Priority, TicketRef
from vcity.tickets.drafts import TicketDraft
from vcity.tickets.sinks import TicketSink, TicketSinkError

_log = logging.getLogger(__name__)


class OutboxStore:
    def __init__(self, path: Path) -> None:
        path.parent.mkdir(parents=True, exist_ok=True)
        self._path = path
        with closing(sqlite3.connect(path)) as db, db:
            db.execute(
                "create table if not exists pending(id text primary key, draft text not null)"
            )

    def put(self, draft: TicketDraft) -> None:
        with closing(sqlite3.connect(self._path)) as db, db:
            db.execute(
                "insert or replace into pending values (?, ?)", (str(draft.id), _dump(draft))
            )

    def pending(self) -> list[TicketDraft]:
        with closing(sqlite3.connect(self._path)) as db:
            return [_load(str(row[0])) for row in db.execute("select draft from pending")]

    def remove(self, ticket_id: UUID) -> None:
        with closing(sqlite3.connect(self._path)) as db, db:
            db.execute("delete from pending where id = ?", (str(ticket_id),))


class OutboxSink:
    def __init__(
        self, inner: TicketSink, store: OutboxStore, *, timeout: float = 3.0, attempts: int = 2
    ) -> None:
        self._inner = inner
        self._store = store
        self._timeout = timeout
        self._attempts = attempts

    async def create(self, draft: TicketDraft) -> TicketRef:
        for attempt in range(1, self._attempts + 1):
            try:
                async with asyncio.timeout(self._timeout):
                    return await self._inner.create(draft)
            except (TicketSinkError, TimeoutError):
                _log.warning("ticket %s attempt %d failed", draft.reference, attempt, exc_info=True)
        self._store.put(draft)
        return TicketRef(draft.reference, url=None)

    async def flush(self) -> int:
        sent = 0
        for draft in self._store.pending():
            try:
                async with asyncio.timeout(self._timeout):
                    await self._inner.create(draft)
            except (TicketSinkError, TimeoutError):
                _log.warning("outbox still cannot send %s", draft.reference, exc_info=True)
                continue
            self._store.remove(draft.id)
            sent += 1
        return sent

    async def run(self, interval: float = 60.0) -> None:
        while True:
            await asyncio.sleep(interval)
            await self.flush()


class _StoredDraft(BaseModel):
    model_config = ConfigDict(frozen=True)

    id: UUID
    title: str
    description: str
    labels: frozenset[str]
    priority: Priority


def _dump(draft: TicketDraft) -> str:
    return _StoredDraft(
        id=draft.id,
        title=draft.title,
        description=draft.description,
        labels=draft.labels,
        priority=draft.priority,
    ).model_dump_json()


def _load(raw: str) -> TicketDraft:
    stored = _StoredDraft.model_validate_json(raw)
    return TicketDraft(
        id=stored.id,
        title=stored.title,
        description=stored.description,
        labels=stored.labels,
        priority=stored.priority,
    )
```

```python
import hashlib
import hmac
import json
import re
from datetime import datetime
from pathlib import Path
from typing import Protocol

from vcity.knowledge.model import SearchStatus, SourceKind

_SCRUBBERS = (
    (re.compile(r"[\w.+-]+@[\w-]+(\.[\w-]+)+"), "[email]"),
    (re.compile(r"(\+?1[\s.-]?)?\(?\d{3}\)?[\s.-]?\d{3}[\s.-]?\d{4}\b"), "[phone]"),
    (re.compile(r"\d{5,}"), "[number]"),
)


class GapLog(Protocol):
    def record(
        self,
        *,
        at: datetime,
        query: str,
        kind: SourceKind | None,
        status: SearchStatus,
        caller_id: str | None,
    ) -> None: ...


def scrub(text: str) -> str:
    for pattern, replacement in _SCRUBBERS:
        text = pattern.sub(replacement, text)
    return text


def hash_caller(caller_id: str, salt: str) -> str:
    return hmac.new(salt.encode(), caller_id.encode(), hashlib.sha256).hexdigest()[:16]


class JsonlGapLog:
    def __init__(self, path: Path, salt: str) -> None:
        if not salt:
            raise ValueError("a gap log needs a non-empty salt to hash caller IDs")
        self._path = path
        self._salt = salt

    def record(
        self,
        *,
        at: datetime,
        query: str,
        kind: SourceKind | None,
        status: SearchStatus,
        caller_id: str | None,
    ) -> None:
        entry = {
            "at": at.isoformat(),
            "query": scrub(query),
            "kind": kind,
            "status": status,
            "caller": hash_caller(caller_id, self._salt) if caller_id else None,
        }
        self._path.parent.mkdir(parents=True, exist_ok=True)
        with self._path.open("a", encoding="utf-8") as log:
            log.write(json.dumps(entry) + "\n")


class CompositeGapLog:
    def __init__(self, *logs: GapLog) -> None:
        self._logs = logs

    def record(
        self,
        *,
        at: datetime,
        query: str,
        kind: SourceKind | None,
        status: SearchStatus,
        caller_id: str | None,
    ) -> None:
        for log in self._logs:
            log.record(at=at, query=query, kind=kind, status=status, caller_id=caller_id)
```
