# M6: Deploy the Web Call Line, Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put `/call` on a public Cloud Run URL behind a server-checked access code, one call at a time with a 10-minute cap, deployed keylessly from `main` once every eval layer passes.

**Architecture:** A small `vcity.gate` package holds the access-code check, the guess lockout, single-use call tickets and the one-call line. `app.py` exposes them through `GET/POST /session` and checks the ticket on `/ws/browser`. The call gets a deadline, the process recycles itself when memory is high and idle, and the ticket outbox drains on shutdown. A Dockerfile, an idempotent `gcloud` setup script and reusable GitHub workflows (WIF, no keys) deliver it.

**Tech Stack:** Python 3.12, FastAPI/Starlette, Pipecat 1.14, Docker, Google Cloud Run, Artifact Registry, Secret Manager, Workload Identity Federation, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-26-m6-deploy-design.md` (approved 2026-10-26). Project rules: `CLAUDE.md`.

## Review Focus

1. **A ticket reused** (page refresh, a replayed URL): the second socket must close `1008` before any pipeline work. Pinned in Task 1 (`test_a_ticket_works_once`) and Task 2 (`test_a_used_ticket_is_refused`).
2. **The caller closes the tab mid-call, or the call raises:** the line must be free afterwards, or the demo stays "busy" forever. Pinned in Task 2 (`test_the_line_is_freed_when_the_call_fails`).
3. **The right code during a lockout:** must still get `429`, or the lockout is only a delay for a guesser who eventually guesses right. Pinned in Task 1 (`test_a_lockout_refuses_even_the_right_code`) and Task 2.
4. **Expired tickets piling up** when a page gets tickets and never connects: the table must prune. Pinned in Task 1 (`test_expired_tickets_are_pruned`).
5. **Browser storage blocked** (private window, Safari settings): the page must still call, just asking for the code each time. Pinned in Task 6 (every `sessionStorage` access in `try/catch`, checked in the manual browser step).

### Task 6: The call page asks for the code

**Files:**
- Modify: `src/vcity/voice/static/call.html`
- Test: `tests/test_app.py`

**Interfaces:**
- Consumes: Task 2's `/session` endpoints; Task 3's `call-ended` server message.

**Behaviour, exactly:**
- **Markup.** A `<form id="code-form" hidden>` directly above the orb, inside `#stage`. It holds `<label for="code">Access code</label>` and `<input id="code" type="password" autocomplete="off" required>`. Submitting the form, with Enter, runs the same start flow as clicking the orb. Style it with the existing tokens, keeping the Circle City look: a rounded field, `--leaf` focus ring, at least a 44 px touch target, and a phone width that fits.
- **On load:** `GET /session`. If `code_required` is true, or the request fails, and there is no stored code, show the form. Read and write `sessionStorage` key `vcity-access-code` only inside `try/catch`. A failure means nothing is stored.
- **Start flow**, from the orb or the form:
  1. Get the code from storage or the field.
  2. If a code is required and there is none, focus the field and show status `Enter the access code to call.`
  3. `POST /session` with `{"code": code}`.
  4. On `200`, store the code, hide the form, and `client.connect({ wsUrl: \`${scheme}://${location.host}/ws/browser?ticket=${encodeURIComponent(ticket)}\` })`.
- **Statuses** (set after `setState("idle")`):
  - `401`: clear stored code, show and focus the form, `That code didn't work. Check it and try again.`
  - `409`: `The line is busy. Try again in a minute.`
  - `429`: `Too many wrong codes. Wait a minute and try again.`
  - Any other failure, including a network error, keeps the existing `Couldn't connect. Try again.`, and the existing microphone message stays as is.
- **Time limit.** `onServerMessage` with `type === "call-ended"` and `reason === "time-limit"` sets a flag. `onDisconnected` then shows status `Calls are limited to 10 minutes.` instead of `Call ended.`, and clears the flag. The flag is also cleared at the start of every call.
- **Safe DOM.** Build everything with `textContent`, never `innerHTML` from variables.
