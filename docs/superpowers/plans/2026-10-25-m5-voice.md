# M5: The Voice Line — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Callers can talk to the agent from a browser at `/call`, which gives the experience of a phone line:
- streaming speech with about 1–1.5 s to the first audio
- barge-in, with history that keeps only what the caller heard
- recorded hold lines while tools run
- per-turn latency logging
- an audio smoke test (spec eval layer 4)

**Architecture:**
- **Audio:** Pipecat 1.14 owns the audio. A FastAPI WebSocket with protobuf frames feeds Silero VAD and Smart Turn v3, then Deepgram Nova-3, then our agent, then ElevenLabs Flash.
- **Agent:** the agent is the same `Conversation` the text eval tests, wrapped in a small `AgentProcessor`. `Conversation` gains a streaming API, plus `heard()` to reconcile its history after an interruption.
- **Transfers:** a browser transfer is shown on screen and then the call ends. Twilio is M6.

**Tech Stack:**
- `pipecat-ai[deepgram,elevenlabs,websocket]==1.14.0`
- `uvicorn`, FastAPI (via Pipecat)
- Pipecat's JS client from esm.sh
- Deepgram Nova-3, ElevenLabs `eleven_flash_v2_5`
- Claude Haiku 5.5 with adaptive thinking

**Spec:** `docs/spec.md`:
- §3: architecture
- §6: waiting
- §9: latency and barge-in
- §10 layer 4: audio smoke
- §11: manual workflows
- §13: the voice time box, 1 working day; any Vapi fallback needs Eyal's approval

## Decisions this plan makes (review these first)

All of these were prototyped on 2026-10-25 against the real Deepgram, ElevenLabs, Anthropic and Voyage APIs.

| # | Question | Decision | Alternatives |
|---|---|---|---|
| D1 | How does voice drive the agent? | A custom Pipecat `AgentProcessor` wraps our `Conversation`. Pipecat handles only audio, turn detection, TTS and metrics, so the scenario eval tests exactly what voice runs. | Pipecat's `AnthropicLLMService`, which would duplicate the tool loop, caching and prompt in Pipecat's shapes. |
| D2 | How does speech start early? | `Conversation.stream(caller)` yields `Speech(text)` deltas, `ToolsRunning(names)` and `Done(turn)`, and `reply()` is built on it. At each tool boundary the processor flushes the TTS sentence buffer, so a lead-in isn't held until more text arrives. That flush alone cut the first audio from 3.3 s to 1.5 s. | Non-streaming replies, which take 3–4 s to the first audio. |
| D3 | Thinking (**this reverses M4's D4**) | **Adaptive thinking**, with `max_tokens` raised from 512 to 2048 (see below). | Thinking off plus prompt rules: in every disabled run, `route_request` turns still spoke reasoning aloud ("The caller wants Code Compliance, so I'll route…"). |
| D4 | Who says the lead-in? (**this deviates from spec §6**) | The code does. When a tool starts and nothing has been spoken yet, a recorded "Let me check that." plays at once. A recorded "One moment." follows if the tool is still running 1.5 s later; that delay is the `still_working_after` setting. The clips are generated once with ElevenLabs and committed. | The model writes a lead-in itself, as spec §6 says. With thinking on it rarely does, and with thinking off it narrates. |
| D5 | How short are answers? | The prompt asks for at most two short sentences, under 30 words, with no backstage talk. The scenario gate gains two exact checks on every turn: at most 50 words, and never "the caller" or a tool name. Measured: median 27 words, p90 41 (before: 41 and 60). One scenario check changed from "bee" to "bee\|hive". | Only report length (judge "speakable"), which doesn't gate it. |
| D6 | Barge-in and history | Pipecat cancels the processor task when the caller interrupts. `Conversation` already appends history only after tools finish, so a cancel leaves it valid. On an interrupted turn, the assistant aggregator's spoken-only text goes to `Conversation.heard(spoken)`, which replaces the unspoken answer with what was heard (or appends it if the round was cut short). | Keep the full answer in history, which breaks spec §9. |
| D7 | Browser transport | `FastAPIWebsocketTransport` with `ProtobufFrameSerializer`. `/call` is one static page that loads `@pipecat-ai/client-js@1.14.0` and `@pipecat-ai/websocket-transport@1.8.0` from esm.sh, so there's no JS build step. Twilio in M6 swaps only the serializer. | SmallWebRTC, which is heavier and awkward over UDP on Render. A hand-written serializer and JS. |
| D8 | Transfers in the browser | A `ScreenTransfer` port records the request. After the reply, the processor sends an RTVI server message `{"type": "transfer", "department"}`, which the page shows, then an `EndWorkerFrame` to end the call. | Keep the call open after a "transfer". |
| D9 | Latency logging (spec §9) | Pipecat's `UserBotLatencyObserver` produces a per-turn breakdown: endpointing, transcription, turn detection, LLM inference, sentence aggregation, speech synthesis and total. It's logged per turn and sent to the page. The processor emits TTFB metrics so the LLM stage gets its own line. | Hand-rolled timers. |
| D10 | Voice and models | ElevenLabs `eleven_flash_v2_5` at 24 kHz with the premade voice `XrExE9yKIg1WjnnlVkGX` ("Matilda") as the default `ELEVENLABS_VOICE_ID`. The free plan blocks library voices through the API, and a public voice ID isn't a secret. Deepgram Nova-3 with Pipecat defaults. | The Starter plan, about $5 a month, for library voices. |
| D11 | Typing at the Pipecat boundary | Pipecat ships `py.typed` but leaves `**kwargs` and event-handler registration unannotated. pyright's `reportUnknownMemberType` is turned off **only** for `src/vcity/voice` and `evals/audio`, through `executionEnvironments`. Everything else stays strict. Two Pipecat-internal deprecation warnings (`audioop`, `AudioContextTTSService`) are filtered in pytest. | Stub out Pipecat, or loosen pyright for the whole repo. |
| D12 | Audio smoke test (spec §10 layer 4) | `python -m evals.audio` streams 3 recorded callers (chickens, weekend events, a police transfer) into the running server in real time. It checks what's said, whether a transfer happened, and that the first audio arrives within 2 s. It runs as the manual `audio-smoke` workflow. **It needs the new repo secrets `DEEPGRAM_API_KEY` and `ELEVENLABS_API_KEY`.** | Run it on every push, which spends ElevenLabs credits. |
| D13 | What M5 doesn't do | Twilio and phone transfers (M6). Render deploy and memory checks (M7). The events search's "this weekend" inconsistency, an open M2 carry-over, is noted for the writeup. | — |

**D3, measured:**
- **First output:** 0.73 s median with adaptive thinking against 0.62 s with thinking off, on the same prompts.
- **Narration:** none with adaptive thinking.
- **Scenario gate:** 41/42 every run, twice, at LLM p50 about 1.06 s and $0.043 a run (M4 was $0.037).
- **Why `max_tokens` rises:** adaptive thinking counts toward it. At 512, 2 of 16 runs truncated into the fallback reply; at 2048, 0 of 16.

**Measured end to end:** on a local Mac, with the client timing from the end of caller speech to the first agent audio, the three smoke callers took 1.0–1.5 s across repeated runs, against spec §9's ~1.5 s target and 2 s ceiling. Barge-in was verified: a second question interrupting an answer got its own answer, at 1.55 s.

class HangingSearch(NoMatchSearch):
    def __init__(self) -> None:
        self.started = asyncio.Event()

    async def search(
        self,
        query: str,  # noqa: ARG002

type Reply = dict[str, object] | int


BLOCKS = TypeAdapter(list[dict[str, object]])


def sse(body: dict[str, object]) -> bytes:
    events: list[Mapping[str, object]] = [
        {"type": "message_start", "message": {**body, "content": [], "stop_reason": None}}
    ]
    for index, block in enumerate(BLOCKS.validate_python(body["content"])):
        events += [
            {"type": "content_block_start", "index": index, "content_block": _empty(block)},
            *({"type": "content_block_delta", "index": index, "delta": d} for d in _deltas(block)),
            {"type": "content_block_stop", "index": index},
        ]
    events += [
        {
            "type": "message_delta",
            "delta": {"stop_reason": body["stop_reason"], "stop_sequence": None},
            "usage": body["usage"],
        },
        {"type": "message_stop"},
    ]
    return "".join(f"event: {e['type']}\ndata: {json.dumps(e)}\n\n" for e in events).encode()


def _empty(block: dict[str, object]) -> dict[str, object]:
    match block["type"]:
        case "text":
            return {"type": "text", "text": ""}
        case "tool_use":
            return {**block, "input": {}}
        case _:
            return {**block, "thinking": "", "signature": ""}


def _deltas(block: dict[str, object]) -> list[dict[str, object]]:
    match block["type"]:
        case "text":
            return [{"type": "text_delta", "text": block["text"]}]
        case "tool_use":
            return [{"type": "input_json_delta", "partial_json": json.dumps(block["input"])}]
        case _:
            return [
                {"type": "thinking_delta", "thinking": block["thinking"]},
                {"type": "signature_delta", "signature": block["signature"]},
            ]


class FakeAnthropic:
    def __init__(self, replies: Iterator[Reply]) -> None:
        self.replies = replies
        self.requests: list[Request] = []

    def __call__(self, request: httpx2.Request) -> httpx2.Response:
        self.requests.append(Request.model_validate_json(request.content))
        match next(self.replies):
            case int(status):
                return httpx2.Response(status, json={"type": "error", "error": {}})
            case body:
                return httpx2.Response(
                    200, headers={"content-type": "text/event-stream"}, content=sse(body)
                )

    def conversation(
        self,
        model: str = "claude-haiku-5-5",
        search: CitySearchPort | None = None,
        transfers: TransferPort | None = None,
    ) -> Conversation:
        client = AsyncAnthropic(
            api_key="test",

            http_client=httpx2.AsyncClient(transport=httpx2.MockTransport(self)),
        )

        )

        )

class Block(BaseModel):
    model_config = ConfigDict(extra="allow")

    type: str
    id: str | None = None
    tool_use_id: str | None = None


class Message(BaseModel):
    role: str
    content: str | list[Block]

    def blocks(self, kind: str) -> list[Block]:
        return [b for b in self.content if b.type == kind] if isinstance(self.content, list) else []


def parse(messages: list[object]) -> list[Message]:
    return [Message.model_validate(m) for m in messages]


def unpaired_tool_uses(history: list[object]) -> list[str | None]:
    messages = parse(history)
    following = [*messages[1:], Message(role="user", content=[])]
    return [
        use.id
        for current, after in zip(messages, following, strict=True)
        for use in current.blocks("tool_use")
        if use.id not in {r.tool_use_id for r in after.blocks("tool_result")}
    ]

@dataclass(frozen=True, slots=True)
class ToolCall:
    name: str
    input: object
    result: ToolResult


@dataclass(frozen=True, slots=True)
class Usage:
    input_tokens: int = 0
    cache_read_tokens: int = 0
    cache_write_tokens: int = 0
    output_tokens: int = 0

    def __add__(self, other: "Usage") -> "Usage":
        return Usage(
            self.input_tokens + other.input_tokens,
            self.cache_read_tokens + other.cache_read_tokens,
            self.cache_write_tokens + other.cache_write_tokens,
            self.output_tokens + other.output_tokens,
        )


@dataclass(frozen=True, slots=True)

    tool_calls: tuple[ToolCall, ...]
    llm_seconds: tuple[float, ...]

@dataclass

    calls: list[ToolCall] = field(default_factory=list[ToolCall])
    timings: list[float] = field(default_factory=list[float])
    spoken: list[str] = field(default_factory=list[str])
    usage: Usage = field(default_factory=Usage)

    def add(self, message: Message, seconds: float) -> None:
        self.timings.append(seconds)
        self.usage += Usage(
            message.usage.input_tokens,
            message.usage.cache_read_input_tokens or 0,
            message.usage.cache_creation_input_tokens or 0,
            message.usage.output_tokens,
        )
        self.spoken.extend(b.text for b in message.content if b.type == "text")

    @property
    def text(self) -> str:
        return " ".join(part.strip() for part in self.spoken if part.strip())

    def turn(self, text: str) -> "Turn":
        return Turn(text, tuple(self.calls), tuple(self.timings), self.usage)

    text: str


@dataclass(frozen=True, slots=True)
class ToolsRunning:
    names: tuple[str, ...]


@dataclass(frozen=True, slots=True)
class Done:
    turn: Turn


type Event = Speech | ToolsRunning | Done


@dataclass
class Conversation:
    client: AsyncAnthropic
    toolbox: Toolbox
    system: str
    call: CallContext
    clock: Callable[[], datetime]
    model: str = AGENT_MODEL
    max_tokens: int = 2048
    history: list[MessageParam] = field(default_factory=list[MessageParam])
    _answered: bool = field(default=False, init=False)

    async def reply(self, caller: str) -> Turn:
        async for event in self.stream(caller):
            if isinstance(event, Done):
                return event.turn
        raise AssertionError

    async def stream(self, caller: str) -> AsyncIterator[Event]:
        self.history.append({"role": "user", "content": caller})
        self._answered = False
        record = _Record()
        for _ in range(MAX_TOOL_ROUNDS):
            message: Message | None = None
            async for item in self._ask():
                if isinstance(item, Speech):
                    yield item
                else:
                    message, seconds = item
                    record.add(message, seconds)
            if message is None:
                break
            assistant: MessageParam = {
                "role": "assistant",
                "content": [_param(b) for b in message.content],
            }
            uses = [b for b in message.content if isinstance(b, ToolUseBlock)]
            if uses and message.stop_reason != "tool_use":
                self.history += [assistant, _not_run(uses)]
                break
            if not uses:
                self.history.append(assistant)
                self._answered = True
                if not record.text:
                    yield Speech(FALLBACK_REPLY)
                yield Done(record.turn(record.text or FALLBACK_REPLY))
                return
            yield ToolsRunning(tuple(u.name for u in uses))
            results = await self._run_tools(uses)
            record.calls.extend(results)
            self.history += [assistant, _results(uses, [c.result for c in results])]
        yield Speech(FALLBACK_REPLY)
        yield Done(record.turn(FALLBACK_REPLY))

    async def _ask(self) -> AsyncIterator[Speech | tuple[Message, float]]:
        started = time.perf_counter()
        try:
            async with self.client.messages.stream(
                model=self.model,
                max_tokens=self.max_tokens,
                thinking=THINKING,
                system=self._system_blocks(),
                tools=TOOLS,
                messages=self.history,
            ) as response:
                async for text in response.text_stream:
                    yield Speech(text)
                message = await response.get_final_message()
        except APIError as error:
            _log.warning("model call failed: %s", type(error).__name__)
            return
        yield message, time.perf_counter() - started

    def heard(self, spoken: str) -> None:
        if self._answered:
            self.history.pop()
            self._answered = False
        if spoken and self.history[-1]["role"] == "user":
            self.history.append({"role": "assistant", "content": spoken})

    def _system_blocks(self) -> list[TextBlockParam]:
        return [
            {"type": "text", "text": self.system, "cache_control": {"type": "ephemeral"}},
            {"type": "text", "text": clock_note(self.clock())},
        ]

    async def _run_tools(self, uses: list[ToolUseBlock]) -> list[ToolCall]:
        async with asyncio.TaskGroup() as group:
            tasks = [group.create_task(self._run_tool(u)) for u in uses]
        return [
            ToolCall(u.name, u.input, task.result()) for u, task in zip(uses, tasks, strict=True)
        ]

    async def _run_tool(self, use: ToolUseBlock) -> ToolResult:
        try:
            return await self.toolbox.run(use.name, use.input, self.call)
        except Exception as error:  # noqa: BLE001
            _log.warning("tool %s failed: %s", use.name, type(error).__name__)
            return ToolResult(_TOOL_FAILED_REPLY, is_error=True)


def _param(block: ContentBlock) -> ContentBlockParam:
    match block.type:
        case "text":
            return {"type": "text", "text": block.text}
        case "tool_use":
            return {"type": "tool_use", "id": block.id, "name": block.name, "input": block.input}
        case "thinking":
            return {"type": "thinking", "thinking": block.thinking, "signature": block.signature}
        case "redacted_thinking":
            return {"type": "redacted_thinking", "data": block.data}
        case _:
            raise ValueError(f"unexpected content block {block.type}")


def _tool_result(use: ToolUseBlock, result: ToolResult) -> ToolResultBlockParam:
    return {
        "type": "tool_result",
        "tool_use_id": use.id,
        "content": result.content,
        "is_error": result.is_error,
    }


def _results(uses: list[ToolUseBlock], results: list[ToolResult]) -> MessageParam:
    return {
        "role": "user",
        "content": [_tool_result(u, r) for u, r in zip(uses, results, strict=True)],
    }


def _not_run(uses: list[ToolUseBlock]) -> MessageParam:
    return _results(uses, [ToolResult(_NOT_RUN_REPLY, is_error=True)] * len(uses))

It answers each non-speculative `LLMContextFrame` with `LLMFullResponseStartFrame`, `LLMTextFrame`s and `LLMFullResponseEndFrame`. It flushes at tool boundaries and plays the hold lines. After a transfer it pushes an RTVI `{"type": "transfer", "department"}` message and an `EndWorkerFrame`.

The hold clips must be `SpeechOutputAudioRawFrame`, not plain `OutputAudioRawFrame`. Pipecat only counts speech frames as the bot speaking, which drives the latency observer and barge-in.

`can_generate_metrics()` returns True so the processor's TTFB metric names the "LLM inference" stage in the latency breakdown.

`EndWorkerFrame` ends the worker gracefully after queued audio. A plain `EndFrame` is dropped by the output serializer.

import asyncio
from dataclasses import dataclass

from pipecat.frames.frames import (
    EndFrame,
    Frame,
    LLMContextFrame,
    LLMFullResponseEndFrame,
    LLMFullResponseStartFrame,
    LLMTextFrame,
    SpeechOutputAudioRawFrame,
)
from pipecat.processors.frame_processor import FrameDirection, FrameProcessor
from pipecat.processors.frameworks.rtvi.frames import RTVIServerMessageFrame
from pydantic import BaseModel, ValidationError

from vcity.agent.conversation import Conversation, Done, Speech, ToolsRunning
from vcity.voice.browser_transfer import ScreenTransfer


@dataclass(frozen=True, slots=True)
class HoldLines:
    lead_in: SpeechOutputAudioRawFrame
    still_working: SpeechOutputAudioRawFrame
    still_working_after: float


class AgentProcessor(FrameProcessor):
    def __init__(
        self, conversation: Conversation, transfers: ScreenTransfer, hold: HoldLines
    ) -> None:
        super().__init__(name="agent")
        self._conversation = conversation
        self._transfers = transfers
        self._hold = hold

    def can_generate_metrics(self) -> bool:
        return True

    async def process_frame(self, frame: Frame, direction: FrameDirection) -> None:
        await super().process_frame(frame, direction)
        if isinstance(frame, LLMContextFrame):
            if not frame.speculation and (caller := _last_user_text(frame)):
                await self._answer(caller)
            return
        await self.push_frame(frame, direction)

    async def _answer(self, caller: str) -> None:
        await self.push_frame(LLMFullResponseStartFrame())
        await self.start_ttfb_metrics()
        waiting: asyncio.Task[None] | None = None
        spoke = False
        try:
            async for event in self._conversation.stream(caller):
                if waiting:
                    waiting.cancel()
                    waiting = None
                match event:
                    case Speech(text=text):
                        await self.stop_ttfb_metrics()
                        await self.push_frame(LLMTextFrame(text))
                        spoke = True
                    case ToolsRunning():
                        await self.push_frame(LLMFullResponseEndFrame())
                        if not spoke:
                            await self.stop_ttfb_metrics()
                            await self.push_frame(self._hold.lead_in)
                            spoke = True
                        await self.push_frame(LLMFullResponseStartFrame())
                        waiting = asyncio.create_task(self._hold_on())
                    case Done():
                        pass
        finally:
            if waiting:
                waiting.cancel()
        await self.push_frame(LLMFullResponseEndFrame())
        if self._transfers.requests:
            department = self._transfers.requests[-1].department
            await self.push_frame(
                RTVIServerMessageFrame(data={"type": "transfer", "department": department.value})
            )
            await self.push_frame(EndFrame())

    async def _hold_on(self) -> None:
        await asyncio.sleep(self._hold.still_working_after)
        await self.push_frame(self._hold.still_working)


class _CallerMessage(BaseModel):
    role: str
    content: str


def _last_user_text(frame: LLMContextFrame) -> str:
    messages: list[object] = list(frame.context.get_messages())
    if not messages:
        return ""
    try:
        message = _CallerMessage.model_validate(messages[-1])
    except ValidationError:
        return ""
    return message.content.strip() if message.role == "user" else ""
```

async def run_browser_call(websocket: WebSocket, services: Services, voice: VoiceSettings) -> None:
    call = CallContext(f"WEB-{uuid.uuid4().hex[:8]}", None)
    transfers = ScreenTransfer()
    conversation = Conversation(
        services.anthropic,
        services.toolbox(transfers=transfers),
        services.system,
        call,
        services.clock,
    )
    transport = FastAPIWebsocketTransport(
        websocket=websocket,
        params=FastAPIWebsocketParams(
            audio_in_enabled=True,
            audio_out_enabled=True,
            audio_out_sample_rate=SAMPLE_RATE,
            add_wav_header=False,
            serializer=ProtobufFrameSerializer(),
        ),
    )
    stt = DeepgramSTTService(api_key=voice.deepgram_api_key.get_secret_value())
    tts = ElevenLabsTTSService(
        api_key=voice.elevenlabs_api_key.get_secret_value(),
        sample_rate=SAMPLE_RATE,
        settings=ElevenLabsTTSService.Settings(voice=voice.elevenlabs_voice_id),
    )
    user, assistant = LLMContextAggregatorPair(
        LLMContext(), user_params=LLMUserAggregatorParams(vad_analyzer=SileroVADAnalyzer())
    )
    hold = HoldLines(_clip("let_me_check.wav"), _clip("one_moment.wav"), voice.still_working_after)
    agent = AgentProcessor(conversation, transfers, hold)
    latency = UserBotLatencyObserver()
    worker = PipelineWorker(
        Pipeline([transport.input(), stt, user, agent, tts, transport.output(), assistant]),
        params=PipelineParams(enable_metrics=True, audio_out_sample_rate=SAMPLE_RATE),
        observers=[latency],
    )

    async def on_turn_stopped(
        _: LLMAssistantAggregator, message: AssistantTurnStoppedMessage
    ) -> None:
        if message.interrupted:
            conversation.heard(message.content)

    async def on_breakdown(_: UserBotLatencyObserver, breakdown: LatencyBreakdown) -> None:
        stages = {c.label: round(c.duration_secs, 3) for c in breakdown.contributions}
        _log.info("call %s latency %.3fs %s", call.call_id, breakdown.total_secs, stages)
        await worker.queue_frame(
            RTVIServerMessageFrame(
                data={"type": "latency", "total": breakdown.total_secs, "stages": stages}
            )
        )

    async def on_disconnected(*_: object) -> None:
        await runner.cancel()

    assistant.add_event_handler("on_assistant_turn_stopped", on_turn_stopped)
    latency.add_event_handler("on_latency_breakdown", on_breakdown)
    runner = WorkerRunner(handle_sigint=False)
    transport.add_event_handler("on_client_disconnected", on_disconnected)
    await runner.add_workers(worker)
    await runner.run()

import contextlib
from collections.abc import AsyncGenerator
from importlib.resources import files

from fastapi import FastAPI, WebSocket
from fastapi.responses import HTMLResponse

from vcity.agent.services import Services, open_services
from vcity.settings import AppSettings, VoiceSettings
from vcity.voice.call import run_browser_call

CALL_PAGE = files("vcity.voice").joinpath("static", "call.html").read_text(encoding="utf-8")


def create_app(settings: AppSettings, voice: VoiceSettings) -> FastAPI:
    running: list[Services] = []

    @contextlib.asynccontextmanager
    async def lifespan(_: FastAPI) -> AsyncGenerator[None]:
        async with open_services(settings) as services:
            running.append(services)
            yield

    app = FastAPI(lifespan=lifespan)

    @app.get("/health")
    async def health() -> dict[str, str]:
        return {"status": "ok"}

    @app.get("/call", response_class=HTMLResponse)
    async def call_page() -> str:
        return CALL_PAGE

    @app.websocket("/ws/browser")
    async def browser_call(websocket: WebSocket) -> None:
        await websocket.accept()
        await run_browser_call(websocket, running[0], voice)

    return app

`evals/audio/client.py`:

```python
import asyncio
import contextlib
import time
import uuid
import wave
from dataclasses import dataclass, field
from pathlib import Path

import websockets
from pipecat.frames.frames import (
    InputAudioRawFrame,
    InputTransportMessageFrame,
    OutputAudioRawFrame,
    OutputTransportMessageUrgentFrame,
)
from pipecat.serializers.protobuf import ProtobufFrameSerializer
from pydantic import BaseModel, ValidationError

CHUNK_SECONDS = 0.02
LEAD_SILENCE_SECONDS = 0.5
LISTEN_SECONDS = 12.0
CLIENT_READY = {
    "label": "rtvi-ai",
    "type": "client-ready",
    "data": {"version": "1.0.0", "about": {"library": "vcity-audio-smoke"}},
}


class _Message(BaseModel):
    type: str
    data: dict[str, object] = {}


@dataclass
class Heard:
    first_audio_seconds: float | None = None
    caller_transcript: list[str] = field(default_factory=list[str])
    agent_said: list[str] = field(default_factory=list[str])
    transfers: list[str] = field(default_factory=list[str])

    @property
    def spoken(self) -> str:
        return " ".join(self.agent_said)


async def call(url: str, wav: Path) -> Heard:
    with wave.open(str(wav), "rb") as clip:
        rate, pcm = clip.getframerate(), clip.readframes(clip.getnframes())
    serializer = ProtobufFrameSerializer()
    heard = Heard()
    step = int(rate * CHUNK_SECONDS) * 2
    async with websockets.connect(url, max_size=None) as socket:

        async def send(frame: OutputAudioRawFrame | OutputTransportMessageUrgentFrame) -> None:
            if data := await serializer.serialize(frame):
                await socket.send(data)

        async def stream(audio: bytes) -> None:
            for start in range(0, len(audio), step):
                await send(OutputAudioRawFrame(audio[start : start + step], rate, 1))
                await asyncio.sleep(CHUNK_SECONDS)

        async def listen(spoke_at: list[float]) -> None:
            async for raw in socket:
                frame = await serializer.deserialize(raw)
                if (
                    isinstance(frame, InputAudioRawFrame)
                    and spoke_at
                    and heard.first_audio_seconds is None
                ):
                    heard.first_audio_seconds = time.perf_counter() - spoke_at[0]
                elif isinstance(frame, InputTransportMessageFrame):
                    _record(heard, frame.message)

        await send(
            OutputTransportMessageUrgentFrame(message={**CLIENT_READY, "id": uuid.uuid4().hex})
        )
        spoke_at: list[float] = []
        listener = asyncio.create_task(listen(spoke_at))
        silence = bytes(step)
        await stream(silence * int(LEAD_SILENCE_SECONDS / CHUNK_SECONDS))
        await stream(pcm)
        spoke_at.append(time.perf_counter())
        with contextlib.suppress(websockets.ConnectionClosed):
            await stream(silence * int(LISTEN_SECONDS / CHUNK_SECONDS))
        listener.cancel()
    return heard


def _record(heard: Heard, raw: object) -> None:
    try:
        message = _Message.model_validate(raw)
    except ValidationError:
        return
    match message.type, message.data:
        case "user-transcription", {"final": True, "text": str(text)}:
            heard.caller_transcript.append(text)
        case "bot-output", {"aggregated_by": "sentence", "text": str(text)}:
            heard.agent_said.append(text)
        case "server-message", {"type": "transfer", "department": str(department)}:
            heard.transfers.append(department)
        case _:
            pass
```

`evals/audio/__main__.py`:

````python
import argparse
import asyncio
import os
import sys
from collections.abc import Sequence
from pathlib import Path

from evals.audio.client import Heard, call
from evals.audio.model import FIRST_AUDIO_CEILING, HERE, AudioCase, load_cases


def problems(case: AudioCase, heard: Heard) -> list[str]:
    spoken = heard.spoken.casefold()
    found = [
        f"never said {mention!r}"
        for mention in case.expect.mentions
        if not any(option.casefold() in spoken for option in mention.split("|"))
    ]
    if case.expect.transfer is not None and case.expect.transfer.value not in heard.transfers:
        found.append(f"no transfer to {case.expect.transfer}")
    if heard.first_audio_seconds is None:
        found.append("the agent never spoke")
    elif heard.first_audio_seconds > FIRST_AUDIO_CEILING:
        found.append(f"first audio after {heard.first_audio_seconds:.2f}s")
    return found


async def run(url: str, cases: Sequence[AudioCase]) -> list[str]:
    lines: list[str] = []
    for case in cases:
        heard = await call(url, HERE / case.wav)
        found = problems(case, heard)
        latency = f"{heard.first_audio_seconds:.2f}s" if heard.first_audio_seconds else "-"
        lines.append(f"{'PASS' if not found else 'FAIL'} {case.id}: first audio {latency}")
        lines += [f"  heard: {' '.join(heard.caller_transcript)}", f"  said: {heard.spoken}"]
        lines += [f"  problem: {p}" for p in found]
    return lines


def main(argv: Sequence[str] | None = None) -> None:
    parser = argparse.ArgumentParser(description="Play recorded callers into the voice line.")
    parser.add_argument("--url", default="ws://localhost:8080/ws/browser")
    args = parser.parse_args(argv)
    lines = asyncio.run(run(args.url, load_cases()))
    report = "\n".join(lines)
    sys.stdout.write(report + "\n")
    if summary := os.environ.get("GITHUB_STEP_SUMMARY"):
        with Path(summary).open("a", encoding="utf-8") as out:
            out.write(f"```\n{report}\n```\n")
    sys.exit(1 if any(line.startswith("FAIL") for line in lines) else 0)


if __name__ == "__main__":
    main()
````
