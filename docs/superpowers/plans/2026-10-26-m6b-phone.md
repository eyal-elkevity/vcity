# M6b Phone Line Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Twilio trial number answers with the same agent as `/call`, and a transfer rings `TRANSFER_TO` behind a press-1 whisper, falling back to a spoken `transfer_failed` ticket.

**Architecture:** Signed Twilio webhooks in `src/vcity/telephony/` return TwiML that streams the call to `/ws/twilio`. The existing pipeline runs there through a shared `run_call` with a Twilio transport. When the stream closes, the outcome recorded per `CallSid` decides the next TwiML: dial, time-limit goodbye, busy, or hang up.

**Tech Stack:** FastAPI, Pipecat 1.14.0 (`TwilioFrameSerializer`), `xml.etree.ElementTree`, `hmac`, pytest.

**Spec:** `docs/superpowers/specs/2026-10-26-m6b-phone-design.md` (with `docs/spec.md` §8).

## Global Constraints

- Every Twilio HTTP webhook validates `X-Twilio-Signature`; failure is HTTP 403 with an empty body.
- Signature: Base64(HMAC-SHA1(token, url + concat(sorted(name + value)))). Test vector: URL `https://example.com/myapp.php?foo=1&bar=2`, params `Digits=1234`, `To=+18005551212`, `From=+14158675310`, `Caller=+14158675310`, `CallSid=CA1234567890ABCDE`, token `12345` → `L/OH5YylLD5NRKLltdqwSvS0BnU=`.
- TwiML is built with `xml.etree.ElementTree` and returned as `application/xml`; never by string formatting.
- `TwilioFrameSerializer` runs with `auto_hang_up=False`.
- Phone pipeline sample rate 8000; browser stays 24000.
- Phone and browser share one `CallLine`, one `TicketBook`, one `MemoryRecycler`, and `max_call_seconds`.
- The phone uses the real clock (`HoursMode.REAL`).
- Call id `TEL-` + last 8 chars of `CallSid`. Logs carry only that id, outcomes and counts — never `From`, `To`, `TRANSFER_TO`, `Digits`, summaries or whisper text.
- `transfer_failed` tickets pass `next_open=None`.
- `PhoneCalls` entries expire after 1800 s.
- Dial `timeout="20"`, whisper `Gather` `numDigits="1"` `timeout="8"`.
- Routes mounted only when `TWILIO_AUTH_TOKEN` is set.
- Fixed lines (exact copy):
  - busy: "The city line is busy. Please try again in a minute."
  - time limit: "Calls on this line are limited to ten minutes. Goodbye."
  - whisper: "Corona city line. {department} transfer. The caller says: {summary}. Press 1 to accept."
  - failed with ticket: "Sorry, nobody could take your call right now. I've filed a ticket, reference {digits}. Someone will call you back."
  - failed without ticket: "Sorry, nobody could take your call right now, and I couldn't file a ticket. Please call again later."
- Repo rules: ruff, ruff format, pyright strict (no `# type: ignore`), pytest; comments only for external quirks; Conventional Commits with a why-body and the session trailers.

## Review Focus

1. **A caller hangs up while the whisper plays.** The dial ends unaccepted, so a `transfer_failed` ticket is still filed (it carries the callback number) and the `<Say>` goes nowhere. Pinned in Task 6 (`test_unaccepted_dial_files_a_ticket_and_reads_it`).
2. **An unknown or expired `CallSid` reaches `after-stream` or `dial-status`.** The answer is `<Hangup/>`, never a 500. Pinned in Task 6.
3. **A summary with `<`, `&` or non-ASCII text in the whisper.** It must be escaped, not break the XML. Pinned in Task 2.
4. **The stream's first messages arrive out of order or without a ticket.** The socket closes before any pipeline work. Pinned in Task 4 and Task 6.
5. **A browser call is running when the phone rings.** The phone caller hears the busy line, and the browser call is untouched. Pinned in Task 6.

```python
class TelephonySettings(BaseSettings):     # env_file=".env", extra="ignore", frozen=True, from_env()
    twilio_auth_token: SecretStr | None = None

# Toolbox
async def file_transfer_failed(self, request: TransferRequest, call: CallContext) -> TicketRef | None
    # service_ticket(ServiceRequest(call.call_id, request.department, request.summary, None, call.caller_id),
    #   TicketReason.TRANSFER_FAILED, self.directory[request.department].name,
    #   ticket_id=uuid.uuid4(), next_open=None); None on TicketSinkError (log the reference only)

type PhoneRunner = Callable[[WebSocket, StreamStart, str | None], Awaitable[CallOutcome]]
type TransferTicketer = Callable[[TransferRequest, CallContext], Awaitable[TicketRef | None]]

def telephony_router(*, token: SecretStr, transfer_to: str, line: CallLine, tickets: TicketBook,
                     calls: PhoneCalls, run: PhoneRunner, file_ticket: TransferTicketer,
                     after_call: Callable[[], None]) -> APIRouter
```

Routes (every POST reads `await request.form()` into `dict[str, str]`, then checks the signature against `str(request.url)`; on failure → `Response(status_code=403)`):
- `POST /twilio/voice`: if `line.busy` → `say_and_hang_up(BUSY)`. Else `calls.open(CallSid, From or None)` and → `connect_stream(f"wss://{request.url.hostname}/ws/twilio", tickets.issue(), "/twilio/after-stream")`.
- `WS /ws/twilio`: accept; `start = await read_start(ws)`. On `None` or a failed `tickets.redeem(start.ticket)` → close 1008. If `not line.take()` → `calls.finish(sid, Outcome.BUSY)`, close 4002. Else, in `try/finally` (`line.release(); after_call()`): `outcome = await run(ws, start, call.caller_id)` and map `Transferred` → `finish(TRANSFER, request)`, `TimeLimit` → `finish(TIME_LIMIT)`.
- `POST /twilio/after-stream`, by `calls.get(CallSid)`:
  - outcome `TRANSFER` → `dial(transfer_to, action="/twilio/dial-status", whisper_url="/twilio/whisper", timeout=20)`
  - `TIME_LIMIT` → `close` the entry, then `say_and_hang_up(TIME_LIMIT_LINE)`
  - `BUSY` → `close`, then `say_and_hang_up(BUSY)`
  - else (including an unknown sid) → `close`, then `hang_up()`
- `POST /twilio/whisper`: the request carries `ParentCallSid`. Look up its transfer; if it's missing → `hang_up()`. Else → `whisper(WHISPER.format(department=info_name, summary=request.summary), action="/twilio/whisper-answer", timeout=8)`. For the department name use `request.department.value.replace("_", " ")`.
- `POST /twilio/whisper-answer`: `Digits == "1"` → `calls.accept(ParentCallSid)`, `bridge()`; else `hang_up()`.
- `POST /twilio/dial-status`: `call = calls.close(CallSid)`.
  - `None` or no transfer → `hang_up()`
  - `call.accepted` → `hang_up()`
  - else `ref = await file_ticket(call.transfer, CallContext(call_id, call.caller_id))`, then:
    - `ref` → `say_and_hang_up(FAILED_WITH_TICKET.format(digits=" ".join(ref.reference)))`
    - no `ref` → `say_and_hang_up(FAILED_NO_TICKET)`

`create_app` gains `telephony: TelephonySettings | None = None` and `phone_call: PhoneRunner | None = None` (test seam). When `telephony.twilio_auth_token` is set, it includes the router, sharing the app's `line`, `tickets` and `recycler` (`after_call=lambda: recycler.after_call(line)`). The default runner is `run_call(ws, running[0], voice, web.max_call_seconds, HoursMode.REAL, phone_surface(start, caller_id))`, and `file_ticket=running[0].toolbox().file_transfer_failed`, bound lazily at call time. `__main__` passes `TelephonySettings.from_env()` and runs uvicorn with `proxy_headers=True, forwarded_allow_ips="*"` (comment: Cloud Run terminates TLS, so the scheme Twilio signed only arrives in `X-Forwarded-Proto`).

## Rollout (after the PR merges; each step only when Eyal says go)
