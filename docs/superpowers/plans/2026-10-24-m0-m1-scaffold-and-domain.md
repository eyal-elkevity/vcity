# M0–M1: Scaffold and Domain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Set up the vcity Python project with tooling and CI enforced (M0). Then build the pure business-hours domain that decides between transfer and ticket for each of Corona's 9 departments (M1, which delivers ask 5).

**Architecture:**
- **Packaging.** A `src/vcity` package managed by uv. ruff, pyright in strict mode and pytest all run in GitHub Actions on every push and PR.
- **`vcity.domain`** is pure. It has no I/O, never reads the system clock, and imports none of our other packages. It defines the departments, the opening windows and the `decide` and `next_open` functions.
- **`vcity.config`** sits at the I/O boundary. It loads `data/departments.yaml` through Pydantic and builds the Corona hours policy, which includes the US + California holiday calendar.

**Tech Stack:** Python 3.12, uv, hatchling, ruff, pyright (strict), pytest, Pydantic v2, PyYAML (with types-PyYAML), holidays.

**Spec:** `docs/spec.md`, §2 (city facts), §4 (domain), §11 (CI on push), §12 (engineering standard) and §13 (commits and PRs).

## Global Constraints

- Python `>=3.12`, pinned to 3.12 via `.python-version`.
- Time zone `America/Los_Angeles`. City Hall is open Mon–Thu 07:00–18:00 and closed Friday. The Animal Services shelter is open Mon–Sat 11:00–17:30. Police non-emergency is 24/7.
- Opening windows are half-open: `open <= t < close`. The closing-soon cutoff is 10 minutes and doesn't apply to windows that run to midnight.
- Holidays: `holidays.country_holidays("US", subdiv="CA")`.
- `vcity.domain` must not import from `vcity.config` or any other vcity package, and must not read the system clock.
- No code comments that restate code, narrate changes, or reference tickets or TODOs. Code explains itself through naming and structure, and the reasoning goes in commit messages.
- Commits use Conventional Commits with a body that explains why, and end with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Every commit passes all checks.
- One PR per milestone. The PR description serves as the milestone's design note and ends with `🤖 Generated with [Claude Code](https://claude.com/claude-code)`. The user merges.
- **The GitHub repo `eyal-elkevity/vcity` is PUBLIC.** No personal phone numbers or secrets go in committed files. `transfer_to` is passed in at runtime and never stored in `departments.yaml`. This is a deliberate deviation from spec §4.1, made because the repo is public.

```python
from collections.abc import Mapping
from dataclasses import dataclass
from datetime import timedelta
from enum import IntEnum, StrEnum

FULL_DAY = timedelta(hours=24)


class Department(StrEnum):
    PUBLIC_WORKS = "public_works"
    MAINTENANCE_SERVICES = "maintenance_services"
    UTILITIES = "utilities"
    CODE_COMPLIANCE = "code_compliance"
    ANIMAL_SERVICES = "animal_services"
    BUILDING_PLANNING = "building_planning"
    CITY_CLERK = "city_clerk"
    FINANCE = "finance"
    POLICE_NON_EMERGENCY = "police_non_emergency"


class Weekday(IntEnum):
    MON = 0
    TUE = 1
    WED = 2
    THU = 3
    FRI = 4
    SAT = 5
    SUN = 6


@dataclass(frozen=True, slots=True)
class OpenWindow:
    start: timedelta
    end: timedelta

    def __post_init__(self) -> None:
        if not timedelta(0) <= self.start < self.end <= FULL_DAY:
            raise ValueError(f"invalid opening window {self.start}-{self.end}")

    def contains(self, offset: timedelta) -> bool:
        return self.start <= offset < self.end

    @property
    def runs_to_midnight(self) -> bool:
        return self.end == FULL_DAY


@dataclass(frozen=True, slots=True)
class DepartmentInfo:
    department: Department
    name: str
    description: str
    public_phone: str
    transfer_to: str
    hours: Mapping[Weekday, OpenWindow]
    source_url: str
```

### Task 3 (M1): The routing decision and next-open time

**Files:**
- Create: `src/vcity/domain/hours.py`, `tests/domain/test_hours.py`

**Interfaces:**
- Consumes: `Department`, `Weekday`, `OpenWindow`, `DepartmentInfo` and `FULL_DAY` from Task 2.
- Produces:
  - `class TicketReason(StrEnum)`: `AFTER_HOURS`, `HOLIDAY`, `CLOSING_SOON`, `TRANSFER_FAILED` and `CALLER_REQUESTED`, valued `"after_hours"`, `"holiday"`, `"closing_soon"`, `"transfer_failed"` and `"caller_requested"`
  - `@dataclass(frozen=True, slots=True) class Transfer(number: str)`
  - `@dataclass(frozen=True, slots=True) class Ticket(reason: TicketReason, next_open: datetime | None)`
  - `type RoutingDecision = Transfer | Ticket`
  - `class HolidayCalendar(Protocol)` with `__contains__(self, key: object, /) -> bool`. Both a `frozenset[date]` and a `holidays` calendar satisfy it.
  - `@dataclass(frozen=True, slots=True) class HoursPolicy(tz: ZoneInfo, closing_soon: timedelta, holidays: HolidayCalendar)`
  - `decide(dept: DepartmentInfo, now: datetime, policy: HoursPolicy) -> RoutingDecision`
  - `next_open(dept: DepartmentInfo, now: datetime, policy: HoursPolicy) -> datetime`. It returns the earliest moment at or after `now` when `decide` would return `Transfer`, in `policy.tz`.
  - Both functions raise `ValueError` if `now` is naive. `next_open` raises `LookupError` if the department never opens within 14 days.

    return timedelta(hours=hour)

        name="Test Department",
        description="Test",
        public_phone="+19515550000",
        transfer_to=DEMO_PHONE,
        hours=hours,
        source_url="https://www.coronaca.gov/",

```python
from dataclasses import dataclass
from datetime import date, datetime, time, timedelta
from enum import StrEnum
from typing import Protocol
from zoneinfo import ZoneInfo

from vcity.domain.departments import DepartmentInfo, OpenWindow, Weekday

SEARCH_HORIZON_DAYS = 14


class TicketReason(StrEnum):
    AFTER_HOURS = "after_hours"
    HOLIDAY = "holiday"
    CLOSING_SOON = "closing_soon"
    TRANSFER_FAILED = "transfer_failed"
    CALLER_REQUESTED = "caller_requested"


@dataclass(frozen=True, slots=True)
class Transfer:
    number: str


@dataclass(frozen=True, slots=True)
class Ticket:
    reason: TicketReason
    next_open: datetime | None


type RoutingDecision = Transfer | Ticket


class HolidayCalendar(Protocol):
    def __contains__(self, key: object, /) -> bool: ...


@dataclass(frozen=True, slots=True)
class HoursPolicy:
    tz: ZoneInfo
    closing_soon: timedelta
    holidays: HolidayCalendar


def decide(dept: DepartmentInfo, now: datetime, policy: HoursPolicy) -> RoutingDecision:
    local = _to_local(now, policy.tz)
    if local.date() in policy.holidays:
        return Ticket(TicketReason.HOLIDAY, next_open(dept, now, policy))
    window = dept.hours.get(Weekday(local.weekday()))
    offset = _offset_from_midnight(local)
    if window is None or not window.contains(offset):
        return Ticket(TicketReason.AFTER_HOURS, next_open(dept, now, policy))
    if _is_closing_soon(window, offset, policy):
        return Ticket(TicketReason.CLOSING_SOON, next_open(dept, now, policy))
    return Transfer(dept.transfer_to)


def next_open(dept: DepartmentInfo, now: datetime, policy: HoursPolicy) -> datetime:
    local = _to_local(now, policy.tz)
    for days_ahead in range(SEARCH_HORIZON_DAYS):
        day = local.date() + timedelta(days=days_ahead)
        window = dept.hours.get(Weekday(day.weekday()))
        if window is None or day in policy.holidays:
            continue
        opens = _local_moment(day, window.start, policy.tz)
        if days_ahead > 0 or local < opens:
            return opens
        offset = _offset_from_midnight(local)
        if window.contains(offset) and not _is_closing_soon(window, offset, policy):
            return local
    raise LookupError(f"{dept.name} never opens within {SEARCH_HORIZON_DAYS} days")


def _to_local(now: datetime, tz: ZoneInfo) -> datetime:
    if now.utcoffset() is None:
        raise ValueError("now must be timezone-aware")
    return now.astimezone(tz)


def _offset_from_midnight(local: datetime) -> timedelta:
    return datetime.combine(date.min, local.time()) - datetime.combine(date.min, time())


def _local_moment(day: date, offset: timedelta, tz: ZoneInfo) -> datetime:
    return datetime.combine(day, time(), tzinfo=tz) + offset


def _is_closing_soon(window: OpenWindow, offset: timedelta, policy: HoursPolicy) -> bool:
    return not window.runs_to_midnight and offset >= window.end - policy.closing_soon
```

```python
import re
from datetime import timedelta
from pathlib import Path
from typing import Annotated, Literal, Self

import yaml
from pydantic import BaseModel, ConfigDict, StringConstraints, model_validator

from vcity.domain.departments import Department, DepartmentInfo, OpenWindow, Weekday

DEFAULT_DIRECTORY_PATH = Path(__file__).resolve().parents[3] / "data" / "departments.yaml"
E164 = r"^\+[1-9]\d{7,14}$"

type ClockTime = Annotated[str, StringConstraints(pattern=r"^(([01]\d|2[0-3]):[0-5]\d|24:00)$")]
type DayName = Literal["mon", "tue", "wed", "thu", "fri", "sat", "sun"]
type PhoneNumber = Annotated[str, StringConstraints(pattern=E164)]


class DepartmentEntry(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    name: str
    description: str
    public_phone: PhoneNumber
    schedule: str
    source_url: Annotated[str, StringConstraints(pattern=r"^https://")]


class DirectoryFile(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    schedules: dict[str, dict[DayName, tuple[ClockTime, ClockTime]]]
    departments: dict[Department, DepartmentEntry]

    @model_validator(mode="after")
    def _complete_and_consistent(self) -> Self:
        missing = sorted(set(Department) - self.departments.keys())
        if missing:
            raise ValueError(f"missing departments: {missing}")
        unknown = sorted({e.schedule for e in self.departments.values()} - self.schedules.keys())
        if unknown:
            raise ValueError(f"unknown schedules: {unknown}")
        return self


def load_directory(path: Path, transfer_to: str) -> dict[Department, DepartmentInfo]:
    if not re.fullmatch(E164, transfer_to):
        raise ValueError(f"transfer number must be E.164, got {transfer_to!r}")
    parsed = DirectoryFile.model_validate(yaml.safe_load(path.read_text(encoding="utf-8")))
    weeks = {name: _week(days) for name, days in parsed.schedules.items()}
    return {
        department: DepartmentInfo(
            department=department,
            name=entry.name,
            description=entry.description,
            public_phone=entry.public_phone,
            transfer_to=transfer_to,
            hours=weeks[entry.schedule],
            source_url=entry.source_url,
        )
        for department, entry in parsed.departments.items()
    }


def _week(days: dict[DayName, tuple[ClockTime, ClockTime]]) -> dict[Weekday, OpenWindow]:
    return {
        Weekday[day.upper()]: OpenWindow(_clock_offset(opens), _clock_offset(closes))
        for day, (opens, closes) in days.items()
    }


def _clock_offset(clock: ClockTime) -> timedelta:
    hours, minutes = clock.split(":")
    return timedelta(hours=int(hours), minutes=int(minutes))
```
